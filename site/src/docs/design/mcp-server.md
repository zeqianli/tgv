# Local MCP inspection

`tgv serve` exposes one dataset through four MCP tools over standard input and output. The Rust `rmcp` transport handles MCP messages without opening a network listener. `DatasetState` directly owns core state, repositories, settings, and the track registry. Tool handlers send commands to one worker, which serializes dataset operations because repository types need not be `Send`. The server reuses file classification, per-track loaders, coverage, layout, and rendering instead of introducing separate bioinformatics readers or counting algorithms.

Each client-launched process starts empty. `get_dataset` reports that no dataset is loaded or describes the current reference and tracks. `load_dataset` constructs fresh core state, repositories, and a track registry before swapping them into the worker. A failed replacement leaves the current dataset intact. Track IDs are numeric file positions, shared with the TUI representation, and reset on replacement. The process owns one dataset for its client connection; there is no revision check. An inspection or drawing before a load returns a tool-level `no_dataset` error.

`inspect_interval` takes an explicit, inclusive interval and returns structured statistics. If the contig length is known, an end beyond that length is clamped, while a start beyond it remains invalid. Every inspection reloads its regional alignment data so cached reads from an earlier, wider viewport cannot affect current coverage. BAM queries open a fresh reader while reusing the loaded header and index, because repeating a query at the same BGZF offset with a persistent reader can return no records. Each alignment track summary contains its own coverage method and positions. The overlap count and the single-read TUI renderer use the same alignment query, which includes soft-clipped display spans. The paired TUI renderer filters by the corresponding pair span, including the gap between mates, before calculating rendering contexts. The existing symmetric region representation may load an extra base, but reported positions and interval summaries are restricted to the effective interval.

`draw_viewport` takes a named contig and a 1-based center position, together with a zoom, a genomic half-width, `canvas_width`, `canvas_height`, and a text or ANSI format. The half-width defines the core region requested for loading. The displayed interval is derived from canvas width and zoom, may shift at contig boundaries, and is returned with the drawing. Drawing does not calculate inspection statistics. The server validates request coordinates and canvas dimensions before resolving the layout; the draw response type owns terminal-buffer export and response assembly.

An optional `tracks` array selects numeric IDs for inspection or drawing. The server validates distinct, current IDs and reports selected tracks in dataset file order. Drawing a subset preserves each track's dataset ID rather than renumbering it within the layout. The API labels coverage `viewer_current` and preserves the existing implementation, including its limitations. Auditing coverage, analytical counting options, dynamic track removal, navigation, and multiple datasets are deferred.

The MCP transport reserves standard output for protocol messages and returns successful results in `structuredContent`. Dataset failures return `isError` with a structured code, message, and field. Typed `TGVError` variants retain the tool-specific fields, and one conversion function constructs the MCP response without adding an rmcp dependency to `gv-core`. Closing standard input stops the connection and lets the worker close its repository. A termination signal ends the process immediately because Tokio's stdin reader can remain blocked during runtime shutdown. MCP request types remain separate from session serialization, so the persisted TUI session format is unchanged. Replacing Streamable HTTP with stdio is an intentional transport change.

Verification uses live MCP requests and existing fixtures. No server tests are added while the interface is being explored.
